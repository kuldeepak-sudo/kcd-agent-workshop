Plain English

An assistant that acts on your behalf — never as itself

When you ask this copilot to look something up or issue a refund, it doesn't use its own permissions. It uses a version of your login, narrowed down to exactly the one thing you asked it to do. That narrowing happens automatically, every single time, before the request goes anywhere near the real customer data.

What you're about to see

1

Sign in as yourself

Not as "the bot" — as alice or bob, real support reps with different permissions.

2

Ask for something

"Look up customer C-1024" or "issue a $25 refund." The assistant translates this into a tool call.

3

Your permission gets checked — before anything happens

If you're not allowed to do the thing you asked for, it stops right there with a clear denial. Nothing downstream ever sees the request.

4

If you are allowed: a fresh, narrow token gets minted

Your original login proves who you are broadly. What actually reaches the customer database is a brand-new, short-lived credential that says "this exact person, doing this exact one thing" — nothing more.

5

The Delegation inspector shows you the swap

Click a tool call in the chat and you can see both tokens side by side — same identity, narrower permission.

Why this matters

Without this, an AI agent typically gets ONE broad credential and uses it for everything it does, for everyone it does it for. That means:

  • No way to tell, after the fact, which human actually asked for a given action.
  • No way to give the agent less access for a routine lookup than for a refund.
  • A single leaked agent credential exposes everything the agent can ever do, for every user.

Narrowing the token per-request, per-action, while keeping the human's identity attached, closes all three gaps — and it happens at the infrastructure layer (the gateway), not inside the agent's own code, so no individual agent developer has to remember to implement it correctly.

🔓
Open source note: this exact behavior is usually sold as an Enterprise gateway feature. This demo reimplements it with a small custom open source Tyk plugin instead — same outcome, no paid licence required. See the technical version of this guide for exactly how.
